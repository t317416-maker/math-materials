## ゲームの新ルール

### 【案1】固定駅制
目的地を固定された「駅」として配置し、順番に巡回します。

```
駅の位置: -16, -8, 0, +8, +16
初期位置: 0

1番目の目的地: -16（または-8）
2番目の目的地: -8（または0）
...順番に巡回
```

**メリット:**
- 目的地が予測可能で戦略が立てやすい
- 「次は+8の駅を目指そう」という明確な目標
- 実装がシンプル

---

### 【案2】移動の選択制
計算問題の答えを見てから、移動方向を選択できます。

```
問題: 2x + 3 = 7, x = ?
正解: 2

移動の選択肢:
A) +2マス進む（目的地が右なら有利）
B) -2マス進む（目的地が左なら有利）
C) 移動しない（現在位置がちょうど良い場合）
```

**メリット:**
- 戦略性が大幅UP
- オーバーシュートを防げる
- 「わざと進まない」という選択も可能

---

### 【案5】到達範囲の拡大
駅の±3マス以内に入れば到達とみなします。

```
駅の位置: +8
到達判定: +5, +6, +7, +8, +9, +10, +11 すべて到達!
```

**メリット:**
- 到達しやすさが大幅UP
- 「近づけば勝ち」で分かりやすい

---

### 【案6】答えの固定化
すべての計算問題の答えを1〜5に制限します。

**問題例:**

1. **正負の数の加減**
   - `3 + 2 = ?` → 答え: 5
   - `7 - 4 = ?` → 答え: 3
   - `(-1) + 4 = ?` → 答え: 3

2. **一次方程式**
   - `2x + 1 = 9, x = ?` → 答え: 4
   - `3x - 2 = 7, x = ?` → 答え: 3
   - `x + 5 = 6, x = ?` → 答え: 1

3. **素因数分解**
   - `18 = 2 × ?²` → 答え: 3
   - `12 = ? × 3` → 答え: 4
   - `20 = ? × 5` → 答え: 4

**メリット:**
- 移動がコントロールしやすい
- オーバーシュートが激減
- ゲームバランスが安定

## 実装のポイント

### 1. 駅の管理

```javascript
const stations = [-16, -8, 0, 8, 16];
let currentStationIndex = 0;
let targetStation = stations[currentStationIndex];

function setNextStation() {
  currentStationIndex = (currentStationIndex + 1) % stations.length;
  targetStation = stations[currentStationIndex];
}
```

### 2. 到達判定

```javascript
function checkReach(playerPosition, targetStation) {
  return Math.abs(playerPosition - targetStation) <= 3;
}
```

### 3. 移動の選択UI

### 4. 計算問題の生成

```javascript
function generateProblem() {
  const types = ['addition', 'equation', 'factorization'];
  const type = random(types);
  
  switch(type) {
    case 'addition':
      // 答えが1〜5になるように調整
      const a = random(1, 10);
      const b = random(1, 5);
      const answer = b; // a - (a - b) = b
      return {
        question: `${a} - ${a - b} = ?`,
        answer: answer
      };
    
    case 'equation':
      // 2x + c = d の形で、x = 1〜5
      const x = random(1, 5);
      const c = random(1, 10);
      const d = 2 * x + c;
      return {
        question: `2x + ${c} = ${d}, x = ?`,
        answer: x
      };
    
    case 'factorization':
      // n = k × ?² の形で、答えが2〜5
      const ans = random(2, 5);
      const k = random(2, 6);
      const n = k * ans * ans;
      return {
        question: `${n} = ${k} × ?²`,
        answer: ans
      };
  }
}
```
